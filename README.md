# Sun-Attendance

Fingerprint attendance machine (ESP32, MicroPython, LCD) with a phone-friendly web app.

- `device/`: code uploaded to the ESP32 with Thonny
- `docs/`: the web app, published with GitHub Pages
- `supabase/schema.sql`: the database
- `tests/rules.test.html`: tests for the attendance rules, opened through a local web server

See [SETUP.md](SETUP.md) to install it. Try the app with made-up data by adding `?demo=1` to its address.
